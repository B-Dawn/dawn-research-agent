# 破晓 Dawn · 科研全流程智能体

面向研究生与科研人员的**论文全流程助手**（Web 应用）。**零第三方依赖**——后端只用 Python 标准库（http.server），前端单页原生 HTML/JS，`python web_app.py` 即可运行。

> 作者 by B_Dawn · V0.7.2

## 功能总览

- 🧭 **论文十步走**：从定方向到投稿修回的引导式流程图，每步说明“为什么做 / 怎么做 / 交付什么”，可跳转对应模块，进度按账户保存
- 💬 **智能对话**：自然语言驱动检索 / 对比矩阵 / 选刊 / 方向推荐 / 团队协作；粘贴简历即可启动“十步走到定方向”工作流；支持对话内切换模型
- 📚 **文献与精读**：多源真实检索（arXiv / OpenAlex / Crossref 等，反编造：文献只从真实索引进入）→ 对比矩阵 → 批量精读（技术点 / 创新点 / 空白多维度勾选）
- 🗂️ **文献库**：参考文献文件夹，从检索结果勾选收录，库内检索过滤，综合分析找创新点 + 可行性
- ✍️ **写作与投稿**：AI 写作助手（大纲/初稿/润色/投稿信/审稿回复）、开题报告→论文初稿流水线、选刊（国际 / 国内 / 全部期刊范围）、我的论文台账（Word 导入建档 + 附件下载）
- 🧪 **实验与数据**：实验台账（随机种子/结果登记/复现/CSV 校验）、Welch t 检验统计分析、算法生成与静态校验、自动训练设计、训练集检索与下载（Zenodo API）
- 🤝 **团队协作**：合作对接（用户目录/邀请）→ 协作中心（成员+任务板）→ 论文协作（章节分工/审阅意见/协作者权限：可编辑·仅查看，项目自动收录协作者“我的论文”）
- 🛡️ **评审工作台**：AI 三专家盲审（材料自动去标识化，匿名名单可配置）+ 协作者审核（四维评分/结论/重复提交拒绝）+ **多轮盲审迭代**（修改说明匿名入料，轮次留痕）
- ⚙️ **个人中心**：科研画像（AI 判断 + 人工定稿）、方向推荐、长期记忆（AI 问答自动带上）、设置（模型配置 / 个人信息 / 技能中心：多选、zip 导入导出、自定义技能上传）
- 🎨 白蓝 / 粉色 / 暗夜蓝 / 青绿四套主题；全站登录门禁；顶部多标签页

## 快速开始

```bash
cd skills/research-agent/app
python web_app.py            # 默认 http://127.0.0.1:8787
```

Windows 可直接双击 `install.bat` 安装后用 `run-app.bat` 启动。

**首次启动**会自动创建管理员账户：`admin / Aa123456`（请登录后立即在「设置 → 个人信息」改密；管理员可在「管理员 → 账户管理」创建成员）。

**模型配置**：默认预设腾讯混元（OpenAI 兼容，需自备 API Key）；也支持 DeepSeek / 本地 Ollama / 自定义端点。把服务商给的 API 信息整段粘贴到「设置 → API 信息识别」可自动识别填充。

## 数据与隐私

- 所有运行数据存放在 `skills/research-agent/data/`（已被 `.gitignore` 排除），**不会**提交到仓库
- 服务默认只监听 `127.0.0.1`，跨设备协作需自行部署到局域网主机
- 盲审材料的匿名化名单可在 `data/anonymize.json` 配置：`{"names": ["姓名", "学号"]}`
